Attempt: Hodge Conjecture holds for all smooth projective toric varieties

Statement
Let X be a smooth projective toric variety over C. Then every rational Hodge class in H^{2p}(X, Q) is algebraic. Equivalently, the cycle class map cl: A^p(X) ⊗ Q → H^{2p}(X, Q) is an isomorphism for all p.

Proof sketch
- Setup and notation:
  - Let Σ be a complete, smooth fan in N_R = N ⊗ R for a lattice N ≅ Z^n.
  - Let X = X_Σ be the associated smooth projective toric n-fold.
  - For each ray ρ ∈ Σ(1), denote the corresponding T-invariant prime divisor by D_ρ.
  - Let M = Hom(N, Z) be the character lattice.

- Chow ring of X:
  - The Chow ring A^*(X) is generated by the classes [D_ρ] with two families of relations:
    1) Linear relations: For every m ∈ M, sum_{ρ ∈ Σ(1)} ⟨m, u_ρ⟩ [D_ρ] = 0, where u_ρ is the primitive generator of ρ.
    2) Stanley–Reisner relations: For any set of rays {ρ_1, …, ρ_k} that do not span a cone of Σ, the product [D_{ρ_1}]⋯[D_{ρ_k}] = 0.
  - These relations define the Stanley–Reisner-type quotient ring:
    A^*(X) ≅ Z[D_ρ | ρ ∈ Σ(1)] / (linear, SR).
  - In particular, A^p(X) is spanned by monomials in divisor classes representing closures of T-orbits of codimension p, hence by algebraic cycles.

- Cohomology ring of X:
  - By the Jurkiewicz–Danilov theorem, there is a canonical ring isomorphism
    H^{2*}(X, Z) ≅ Z[D_ρ | ρ ∈ Σ(1)] / (linear, SR),
    and H^{odd}(X, Z) = 0.
  - Moreover, the mixed Hodge structure on H^k(X, Q) is Hodge–Tate. In particular, for projective smooth toric X,
    H^k(X, C) = ⊕_{p} H^{p,p}(X) with H^{p,q}(X) = 0 for p ≠ q.
  - Therefore every cohomology class in H^{2p}(X, Q) is of Hodge type (p,p).

- Identification of cycle class map:
  - Under the above ring isomorphism, the isomorphism H^{2*}(X, Z) ≅ A^*(X) identifies the cohomology class of D_ρ with the cycle class of the divisor D_ρ, and respects products.
  - Hence the cycle class map cl: A^p(X) ⊗ Q → H^{2p}(X, Q) is a Q-linear isomorphism for all p.

- Conclusion:
  - Since every rational (p,p)-class on X lies in H^{2p}(X, Q), and the cycle class map is an isomorphism, every rational Hodge class is algebraic.

Comments on rigor and dependencies
- The only deep inputs are standard toric results (Jurkiewicz–Danilov presentation of cohomology and the identification with the Chow ring) and that smooth projective toric varieties are Hodge–Tate. Both are established by toric geometry methods (e.g., via equivariant cohomology and the spectral sequence degenerating, or via cellular decompositions by orbits and their closures).
- No standard conjectures (like Lefschetz-type) are assumed; all used facts are theorems.

Scope
- This settles the Hodge Conjecture for all smooth projective toric varieties in all codimensions.
- It also applies, via products and toric morphisms, to a broad class of varieties with toric structures (e.g., projective bundles over toric bases), for which the same argument extends by the projective bundle formula and Künneth.
