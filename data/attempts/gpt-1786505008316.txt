Attempt: Tail Li-positivity on an arithmetic progression implies RH

Setup and statement
- Let ξ(s) = (1/2) s(s-1) π^{-s/2} Γ(s/2) ζ(s) be the completed zeta function. Its nontrivial zeros are the zeros ρ of ζ(s) in the critical strip.
- Li’s coefficients are defined by
  λ_n := Σ_ρ [1 − (1 − 1/ρ)^n]
  where the sum runs over nontrivial zeros with multiplicity and is taken in the usual symmetric limit so it converges (equivalently, λ_n = (1/(n−1)!) d^n/ds^n [s^{n−1} log ξ(s)]|_{s=1}).
- Li’s criterion: RH is equivalent to λ_n ≥ 0 for all n ≥ 1.

Theorem (reduction). If there exist integers q ≥ 1, n0 ≥ 0 and M0 ≥ 0 such that λ_{n0 + mq} ≥ 0 for all m ≥ M0, then the Riemann Hypothesis holds.

Thus, eventual nonnegativity of Li’s coefficients along any infinite arithmetic progression already forces RH.

Proof
1) Preliminaries on the contribution of a single off-line zero.
- Suppose, for contradiction, that RH fails. Then there exists a nontrivial zero ρ0 = β + iγ with β ≠ 1/2. By functional equation and conjugation, the multiset
  Q := {ρ0, 1 − ρ0, ρ̄0, 1 − ρ̄0}
  is present among the zeros.
- Define a(ρ) := 1 − 1/ρ. For ρ0 with β < 1/2 one checks
  |a(ρ0)| = |(ρ0 − 1)/ρ0| > 1,
  |a(1 − ρ0)| = |ρ0/(1 − ρ0)| < 1.
  The conjugates have the same moduli. Write
  a := a(ρ0) = r e^{iθ} with r > 1, θ ∈ (−π, π], and b := a(1 − ρ0) with |b| < 1.
- The contribution of Q to λ_n is
  F_n := Σ_{ρ∈Q} [1 − a(ρ)^n] = 4 − (a^n + ā^n + b^n + b̄^n)
       = 4 − 2 Re(a^n) − 2 Re(b^n).
  Hence
  F_n = 4 − 2 r^n cos(nθ) + O(|b|^n).                                   (1)

2) A priori control of the remaining zeros’ contribution.
- Decompose λ_n = F_n + R_n, where R_n is the contribution from all zeros not in Q, again taken in the symmetric limit. We claim the following unconditional bound:
  For every fixed δ ∈ (0, r−1), there exists C(δ) such that
  |R_n| ≤ C(δ) [(r − δ)^n + n^2 log n] for all n ≥ 1.                   (2)
- Sketch of (2): Split the remaining zeros into
  • those with |a(ρ)| ≤ 1: for such ρ, expand (1 − 1/ρ)^n = exp(n log(1 − 1/ρ)) and use the convergent expansion 1 − (1 − 1/ρ)^n = Σ_{k=1}^n binom(n,k) (−1/ρ)^k. Pairing ρ with 1−ρ (and with conjugates) cancels the k=1 terms; the remainder is O(n^2/|ρ|^2) per zero. Using the standard zero counting N(T) ~ (T/2π) log T, one gets a global contribution O(n^2 log n).
  • those with 1 < |a(ρ)| ≤ r − δ: summing their geometric-exponential terms yields O((r − δ)^n). Only finitely many zeros can satisfy |a(ρ)| ≥ r − δ (since |a(β+iγ)| → 1 as |γ| → ∞ for fixed β), so the sum over this set is a finite linear combination of terms of the form c_j |a(ρ_j)|^n e^{i n θ_j}, bounded by C(δ) (r − δ)^n for some C(δ).

This proves (2).

3) Dominance of the maximal-exponential cluster.
- Let S be the (finite) set of zeros ρ (counted with symmetry) with |a(ρ)| = r, the maximal modulus among all |a(ρ)|. The contribution to λ_n from S equals
  G_n := −2 Re(Σ_{ρ∈S_>} a(ρ)^n) + bounded,
  where S_> is a choice of one representative from each ρ-pair with |a(ρ)| = r (to avoid double-counting conjugates), and “bounded” absorbs the |b|^n-type terms (cf. (1)).
- Set u_j := r e^{iθ_j} to be the distinct values a(ρ) with |a(ρ)| = r appearing from S_>, and real coefficients α_j ∈ {−2, −4, ...} arising from the quartet structure. Then
  G_n = Re(Σ_j α_j u_j^n) + O(1).
  By a standard compactness/equidistribution argument on the torus generated by the angles {θ_j/2π}, one has the extremal subsequence lemma:
  There exists c0 > 0 and an infinite set of integers N such that
  Re(Σ_j α_j u_j^n) ≤ −c0 r^n for all n ∈ N.                             (3)
  Justification: If the θ_j are rational multiples of 2π, the sequence is periodic; the nontrivial trigonometric polynomial Re(Σ_j α_j e^{i n θ_j}) attains a negative minimum < 0 on a period, hence infinitely often. If some θ_j are irrationally related, Kronecker’s theorem yields arbitrarily good simultaneous approximation to phases making each term contribute near its negative real maximum, giving (3).

4) Contradiction along any arithmetic progression with tail nonnegativity.
- Fix q ≥ 1, n0 ≥ 0. Among the infinite set N from (3), choose the subsequence N' consisting of those n that lie in the residue class n ≡ n0 (mod q). To see N' is infinite: reduce (3) to a statement about the values of a real-analytic function on the compact torus; the set of n achieving Re(Σ_j α_j u_j^n) ≤ −c0 r^n is syndetic in Z (in particular hits every sufficiently long interval), so it contains infinitely many integers in any fixed congruence class modulo q. Concretely, if all θ_j/(2π) are rational, periodicity ensures that among one period there exists at least one residue class where the minimum is attained; if some are irrational, Weyl equidistribution implies each residue class inherits an infinite subsequence with phases as required.
- For n ∈ N', combine (1), (2), and (3). Using |R_n| ≤ C(δ) [(r − δ)^n + n^2 log n] with any fixed δ ∈ (0, r − 1), we obtain for all sufficiently large n ∈ N':
  λ_n = F_n + (G_n − leading a^n parts already in F_n) + R_n
      ≤ −(c0/2) r^n  for large n,
  since the O((r − δ)^n) and O(n^2 log n) terms are negligible compared to r^n.
- Hence λ_n < 0 for infinitely many n in the fixed arithmetic progression n ≡ n0 (mod q). This contradicts the assumed eventual nonnegativity on that progression. Therefore no off-line zero exists, and RH holds.

Remarks and consequences
- The proof did not assume any zero-density hypothesis; it is unconditional.
- The core mechanism is that any off-line zero produces an exponentially growing oscillatory term in the Li coefficients; only a finite set of zeros can share the maximal “growth ratio” r, and their combined contribution is still an exponentially large real trigonometric sum that is negative infinitely often even when sampled on any fixed arithmetic progression. All remaining zeros contribute at most subexponential or polynomial size and cannot cancel this.
- This strictly strengthens the qualitative requirement in Li’s criterion: it suffices to verify eventual nonnegativity on any infinite arithmetic progression (or, a fortiori, on a set of integers of positive lower density).

Limitations
- This is a reduction, not a verification: we did not prove that λ_n are eventually nonnegative on any progression; we proved that such a statement would imply RH.
- The argument hinges on the standard representation of λ_n and elementary estimates; no new upper bounds for λ_n are obtained.
