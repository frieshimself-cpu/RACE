Attempt: A sharp quantitative barrier for the naive (one-parameter) Beurling–Nyman approximation

Set ρ_a(x) = ⌊a/x⌋ − a/x for x ∈ (0,1] and a ∈ (0,1]. The Beurling–Nyman criterion (in one of its standard forms) states that the linear span of {ρ_a : 0 < a ≤ 1} is dense in L^2(0,1) if and only if the Riemann Hypothesis holds. It is therefore useful to understand how well small-dimensional subspaces generated by these functions can approximate the constant function 1.

This note gives an exact computation for the optimal one-function approximation to 1 by multiples of a single ρ_a, and exhibits a nontrivial lower bound for the L^2(0,1) error which cannot be beaten by any choice of a and scalar multiple. It provides a clean, rigorous “first obstruction” to proving RH by a very naive implementation of the Nyman approach.

Statement
- For any a ∈ (0,1], let ρ_a(x) = ⌊a/x⌋ − a/x on (0,1]. Then
  1) ⟨1, ρ_a⟩ = ∫_0^1 ρ_a(x) dx = a(γ − 1).
  2) ||ρ_a||_2^2 = ∫_0^1 (ρ_a(x))^2 dx = a(ln(2π) − γ − 1).
  In particular, the best L^2 approximation to 1 by a single function c ρ_a
  (with c ∈ ℝ optimized) has squared error
     E_1(a) = 1 − ⟨1,ρ_a⟩^2 / ||ρ_a||_2^2
            = 1 − a (γ − 1)^2 / (ln(2π) − γ − 1).
  Consequently,
     inf_{a∈(0,1], c∈ℝ} ||1 − c ρ_a||_2^2
        = 1 − (γ − 1)^2 / (ln(2π) − γ − 1)
        ≈ 0.3142,
  so the minimal L^2 error is ≈ 0.5607.

Proof

1) The mean ⟨1, ρ_a⟩.

Partition (0,1] into the intervals I_k(a) = (a/(k+1), a/k] for k ≥ 1 (and (a,1] where ⌊a/x⌋ = 0). On I_k(a), we have ⌊a/x⌋ = k and a/x ∈ [k,k+1), hence
∫_{I_k(a)} (⌊a/x⌋ − a/x) dx = ∫_{a/(k+1)}^{a/k} (k − a/x) dx
= k·a(1/k − 1/(k+1)) − a ln((a/k)/(a/(k+1)))
= a(1/(k+1) − ln(1 + 1/k)).
Summing k = 1 to ∞ yields
∫_0^1 ρ_a(x) dx = a ∑_{k=1}^∞ (1/(k+1) − ln(1 + 1/k)).
Since
∑_{k=1}^N 1/(k+1) = H_{N+1} − 1 and ∑_{k=1}^N ln(1 + 1/k) = ln(N+1),
we have as N → ∞,
∑_{k=1}^N (1/(k+1) − ln(1 + 1/k)) = (H_{N+1} − 1) − ln(N+1) → γ − 1.
Therefore ⟨1, ρ_a⟩ = a(γ − 1).

2) The L^2 norm ||ρ_a||_2^2.

Again on I_k(a),
∫_{I_k(a)} (k − a/x)^2 dx
= ∫ (k^2 − 2ka/x + a^2/x^2) dx
= k^2·a(1/k − 1/(k+1)) − 2ka ln(1 + 1/k) + a,
since ∫_{a/(k+1)}^{a/k} x^{-2} dx = (1/a).
Thus
||ρ_a||_2^2 = ∑_{k=1}^∞ [ a(k/(k+1) − 2k ln(1 + 1/k)) + a ]
= a ∑_{k=1}^∞ [ (2k+1)/(k+1) − 2k ln(1 + 1/k) ].
Let
S_N = ∑_{k=1}^N [ (2k+1)/(k+1) − 2k ln(1 + 1/k) ].
Then
∑_{k=1}^N (2k+1)/(k+1) = 2N − (H_{N+1} − 1),
and
∑_{k=1}^N 2k ln(1 + 1/k)
= 2 ∑_{k=1}^N k(ln(k+1) − ln k)
= 2(− ln(N!) + N ln(N+1)).
Hence
S_N = 2N − (H_{N+1} − 1) + 2 ln(N!) − 2N ln(N+1).
By Stirling’s formula ln(N!) = N ln N − N + (1/2) ln(2πN) + o(1),
we get
S_N = ln(2π) − γ − 1 + o(1),
so the series converges to ln(2π) − γ − 1. Therefore
||ρ_a||_2^2 = a(ln(2π) − γ − 1).

3) Best one-parameter approximation.

For fixed a, the best scalar multiple c minimizing ||1 − c ρ_a||_2^2 is
c* = ⟨1, ρ_a⟩ / ||ρ_a||_2^2,
with minimal squared error
E_1(a) = 1 − ⟨1, ρ_a⟩^2 / ||ρ_a||_2^2
= 1 − a (γ − 1)^2 / (ln(2π) − γ − 1).
This decreases in a, so the best choice is a = 1, giving
inf_c ||1 − c ρ_1||_2^2 = 1 − (γ − 1)^2 / (ln(2π) − γ − 1).
Numerically, γ ≈ 0.5772156649 and ln(2π) ≈ 1.8378770664, so
(γ − 1)^2 ≈ 0.178748 and ln(2π) − γ − 1 ≈ 0.260661,
hence
inf_{a∈(0,1], c∈ℝ} ||1 − c ρ_a||_2^2 ≈ 1 − 0.68578 ≈ 0.31422,
and the minimal L^2 error is ≈ 0.56066.

Conclusion and significance

- This shows rigorously that any “one-parameter” Nyman attempt (using only a single Beurling function ρ_a and scaling) cannot approximate the target function 1 more closely than about 0.56 in L^2(0,1).
- It gives a clean quantitative obstruction for this simplest version of the Beurling–Nyman strategy. Any successful approach via this criterion must use genuinely higher-dimensional linear combinations and nontrivial interaction between different parameters a.
- Extending these explicit computations to two or more parameters requires evaluating ⟨ρ_a, ρ_b⟩ for a ≠ b. While symmetry and scaling heuristics suggest a min-kernel structure, a full derivation within this L^2(0,1) framework demands careful summation analogous to the norm computation above; I have not completed that here.
