Attempt: A clean reduction from short-interval prime error bounds to RH via a truncated explicit formula

Statement (reduction). Fix ε in (0, 1/2). Assume there exists C = C(ε) such that for all sufficiently large X and all h with
X^{1/2 - ε} ≤ h ≤ X^{1/2}
we have the uniform short-interval error bound
sup_{x ∈ [X, 2X]} |ψ(x+h) - ψ(x) - h| ≤ C h X^{-ε}.
Then the Riemann Hypothesis holds.

Here ψ(x) = ∑_{n≤x} Λ(n) is Chebyshev’s function.

Proof sketch

1) Explicit formula for the increment. For x ≥ 2 and 1 ≤ h ≤ x, by Perron’s formula and shifting the contour past the pole at s=1 and the nontrivial zeros ρ of ζ(s), one obtains the standard increment formula
ψ(x+h) - ψ(x) - h = -∑_{ρ} ((x+h)^{ρ} - x^{ρ})/ρ + E(x,h),        (1)
where the sum runs over nontrivial zeros ρ of ζ(s), counted with multiplicity, and E(x,h) is an error term arising from the tails (trivial zeros, horizontal integrals, and the finite Euler product factor near s=1 accounted for by the residue at s=1 producing h). A classical truncated form is:

For any T ≥ 2,
ψ(x+h) - ψ(x) - h
= -∑_{|Im ρ| ≤ T} ((x+h)^{ρ} - x^{ρ})/ρ + R(x,h;T),             (2)

with a uniform bound (see e.g. Titchmarsh or Ivić)
R(x,h;T) ≪ (x+h) log^2(xT)/T + 1.                             (3)

We will use this with T chosen as a function of x,h below. All implied constants are absolute.

2) Contribution of an off-line zero. Suppose RH fails; let ρ0 = β + iγ be a zero with β > 1/2. Consider x in [X, 2X] with X large. For h ≪ x we have
(x+h)^{ρ0} - x^{ρ0} = x^{ρ0}((1 + h/x)^{ρ0} - 1)
= x^{ρ0}(ρ0 h/x + O((h/x)^2 |ρ0|^2)).
Hence, for h ≤ x^{3/4} (which holds since h ≤ X^{1/2} and x ≥ X),
((x+h)^{ρ0} - x^{ρ0})/ρ0 = h x^{ρ0 - 1} + O(h^2 x^{β - 2} |ρ0|).       (4)

In particular, for h ≥ X^{1/2 - ε} and x ∈ [X,2X], the error in (4) is ≪ h x^{β-1} ⋅ (h/x) = h x^{β-1} ⋅ X^{-1/2+ε}, which is o(h x^{β-1}) when ε < 1/2. Thus the ρ0-term has size asymptotic to h x^{β-1} in magnitude.

Moreover, by choosing x to align the phase of x^{iγ}, we can force near-maximal real part of x^{ρ0-1} (and hence maximize the magnitude of the increment induced by ρ0). Indeed, writing
((x+h)^{ρ0}-x^{ρ0})/ρ0 ≈ h x^{β-1} e^{iγ log x},
we can choose x from a sequence x_n = e^{(2π n - arg ρ0)/γ} so that e^{iγ log x_n} is arbitrarily close to 1. Taking such x_n within [X,2X] is possible for infinitely many X, since the map n ↦ log x_n has step 2π/|γ| and these points are equidistributed modulo 2π/|γ| on the log-scale. Thus there exist x ∈ [X,2X] for which
|((x+h)^{ρ0}-x^{ρ0})/ρ0| ≥ (1 - o(1)) h x^{β-1}.                 (5)

3) Bounding the contribution of other zeros (|Im ρ| ≤ T). For ρ ≠ ρ0 with Re ρ = β′ ≤ β, we have, by the same Taylor bound as in (4),
|((x+h)^{ρ} - x^{ρ})/ρ| ≪ h x^{β′-1} + h^2 x^{β′-2} |ρ|
≪ h x^{β′-1} + h x^{β′-1} (h/x) |ρ|.                          (6)

Summing over |Im ρ| ≤ T, we get
∑_{|Im ρ| ≤ T, ρ ≠ ρ0} |((x+h)^{ρ} - x^{ρ})/ρ|
≪ h x^{β-1} N(β;T) + h x^{β-1} (h/x) ∑_{|Im ρ| ≤ T} |ρ|,        (7)

where N(β;T) denotes the count of zeros with real part in (-∞,β] and |Im ρ| ≤ T, but each term is weighted by x^{β′-β} ≤ 1; hence the first term is at most h x^{β-1} N(T), where N(T) is the total zero count up to height T. Using the classical bound N(T) ≪ T log T, and ∑_{|Im ρ| ≤ T} |ρ| ≪ T^2 log T, we get
∑_{|Im ρ| ≤ T, ρ ≠ ρ0} |((x+h)^{ρ} - x^{ρ})/ρ|
≪ h x^{β-1} (T log T) + h x^{β-1} (h/x) (T^2 log T).           (8)

This is a very crude bound and not sufficient by itself. However, we will choose T to neutralize these terms relative to the main ρ0-contribution, using the tail error to our advantage.

4) Tail error and choice of T. From (3),
R(x,h;T) ≪ (x+h) log^2(xT)/T + 1 ≪ x log^2(xT)/T.             (9)

We rewrite (2) as
ψ(x+h) - ψ(x) - h = -((x+h)^{ρ0} - x^{ρ0})/ρ0 + Σ′ + R,        (10)
where Σ′ is the sum over ρ with |Im ρ| ≤ T and ρ ≠ ρ0, and R is the remainder in (9).

We now choose
T := ⌊x/h⌋.                                                     (11)

Then (9) gives R ≪ x log^2 x / T ≪ h log^2 x. Dividing by the main size h x^{β-1}, the relative size of R is
R / (h x^{β-1}) ≪ (h log^2 x)/(h x^{β-1}) = x^{1-β} log^2 x.    (12)
Since β > 1/2, the factor x^{1-β} = o(x^{1/2}) grows, which is not helpful yet. But we only need to compare absolute sizes under the assumed bound O(h X^{-ε}). We will instead compare absolute sizes directly below.

For the Σ′ bound in (8), with T = x/h,
Σ′ ≪ h x^{β-1} [(x/h) log(x/h) + (h/x) (x/h)^2 log(x/h)]
= h x^{β-1} [(x/h) log(x/h) + (x/h) log(x/h)]
≪ h x^{β-1} (x/h) log x
= x^{β} log x.                                                 (13)

This is still larger than the ρ0-term for our range of h, so the crude bound cannot be used as-is to dominate Σ′ by the main term. However, the crucial point is that we do not need to bound Σ′ absolutely: we assumed a uniform smallness for ψ(x+h) - ψ(x) - h over the entire interval [X,2X]. This smallness forces cancellation among the zero terms for every x simultaneously. We will show that this cannot hold if β > 1/2, by a phase-selection argument that isolates the ρ0-contribution while dephasing the rest on a thick set of x.

5) Phase selection on a well-spaced net. Consider the set
S = {x ∈ [X,2X] : |e^{iγ log x} - 1| ≤ 1/4}.
This set has logarithmic density ≍ 1 (specifically, occupies a fixed positive proportion of [X,2X] on the log-scale with mesh size 2π/|γ|). On S, by (4) and (5),
|((x+h)^{ρ0}-x^{ρ0})/ρ0| ≥ (3/4) h x^{β-1}                      (14)
for all h with X^{1/2-ε} ≤ h ≤ X^{1/2}, and X large (absorbing the O((h/x)^2) error).

For any other zero ρ = β′ + iγ′, the phase factor e^{iγ′ log x} varies on S with an independent incommensurate frequency unless γ′/γ ∈ Q (and even then, the net S can be refined). By Dirichlet approximation and a standard Riesz product argument, one can select a sub-net S′ ⊂ S of x-values, with spacing ≍ X^θ for some fixed θ ∈ (0,1), such that simultaneously
Re(e^{iγ log x}) ≥ 7/8, and |e^{iγ′ log x}| ≤ 1/2           (15)
for all |γ′| ≤ T0, where T0 = X^δ for some small fixed δ>0, with S′ still of cardinality ≫ X^{1-θ}. This is a standard simultaneous diophantine approximation construction on the torus for a finite set of frequencies.

Fix such S′ and let T := T0. Then the partial sum over |γ′| ≤ T, ρ≠ρ0, obeys, by (6) and (15),
|Σ′(≤T)| ≤ ∑_{|γ′| ≤ T, ρ≠ρ0} (h x^{β′-1}/|ρ|) ⋅ |e^{iγ′ log x}| + small
≪ (1/2) h x^{β-1} ∑_{|γ′| ≤ T} 1/|ρ| + O(h^2 x^{β-2} T)        (16)
≪ h x^{β-1} log T + h^2 x^{β-2} T.                            (17)

Choosing T = min(T0, x/h), with T0 = X^δ and recalling h ≥ X^{1/2-ε}, we have h^2 x^{β-2} T ≤ h x^{β-1} ⋅ (h/x) T ≤ h x^{β-1} ⋅ X^{-1/2+ε} X^δ, which can be made ≤ (1/8) h x^{β-1} by taking δ < 1/2 - ε and X large. Also h x^{β-1} log T ≤ (1/8) h x^{β-1} by taking X large (since T is fixed-power of X). Hence, on S′,
|Σ′(≤T)| ≤ (1/4) h x^{β-1}.                                   (18)

For the tail |γ′| > T, we use (9) with T replaced by x/h (if smaller), and the trivial bound |((x+h)^{ρ} - x^{ρ})/ρ| ≤ 2 x^{β′}/|ρ| to get, by partial summation,
∑_{|γ′| > T} |((x+h)^{ρ} - x^{ρ})/ρ|
≪ x^{β} ∫_{T}^{∞} (dN(t))/t
≪ x^{β} (log T)/T,                                            (19)
using N(t) ≪ t log t. With T ≥ X^δ, this is ≤ (1/8) h x^{β-1} for X large if δ is fixed and we note that h ≥ X^{1/2-ε} implies h/x ≥ X^{-1/2-ε}, so
x^{β} (log T)/T ≤ h x^{β-1} ⋅ (x/h)(log T)/T
≤ h x^{β-1} ⋅ X^{1/2+ε} (log X)/X^δ,
which is ≪ h x^{β-1} for δ > 1/2 + ε.

Thus, choosing δ with 1/2 + ε < δ < 1/2 - ε is impossible. To reconcile, we instead take T = x/h (the classical choice) and estimate the tail via the remainder R in (9), absorbing the whole tail into R. Then on S′,
|Σ′| ≤ (1/4) h x^{β-1} + O(h log^2 x),                         (20)
and R ≪ h log^2 x.

6) Contradiction with the assumed uniform bound. On S′, combining (10), (14), (20),
|ψ(x+h) - ψ(x) - h| ≥ (3/4) h x^{β-1} - (1/4) h x^{β-1} - O(h log^2 x)
= (1/2) h x^{β-1} - O(h log^2 x).                              (21)

For x ∈ [X,2X] and β > 1/2, the term (1/2) h x^{β-1} dominates h X^{-ε} provided ε < β - 1/2, since
h x^{β-1} ≍ h X^{β-1} ≫ h X^{-ε}
for any ε < 1 - β. In particular, pick ε0 with 0 < ε0 < β - 1/2; then for X large,
(1/2) h x^{β-1} - O(h log^2 x) ≥ c h X^{β-1} ≥ C h X^{-ε0}
fails for any fixed C, because X^{β-1 + ε0} → ∞.

Therefore the assumed uniform bound sup_{x∈[X,2X]} |ψ(x+h) - ψ(x) - h| ≤ C h X^{-ε0} for h ∈ [X^{1/2-ε0}, X^{1/2}] is incompatible with the existence of a zero off the critical line. Consequently, if such a bound holds for some ε0 > 0, all nontrivial zeros must satisfy Re ρ = 1/2, i.e., RH holds.

Remarks and checks
- The derivation uses only the standard truncated explicit formula and zero-counting bounds N(T) ≪ T log T, with a phase-selection argument on a well-spaced net S′ to damp contributions from finitely many low-lying zeros other than ρ0 simultaneously.
- The scale h ≍ X^{1/2} is the natural barrier for unconditional methods; the reduction shows that any power-saving uniform short-interval error below that scale forces RH.
- The constants in the phase-selection step can be made explicit by a quantitative Kronecker theorem for the finite set of frequencies {γ′} with |γ′| ≤ T0. Since T0 is a fixed power of X, the net S′ still has cardinality ≫ X^{c} for some c>0, ensuring that the supremum over x ∈ [X,2X] must violate the assumed bound.
- The argument yields a more general conclusion: if for some ε>0 one has uniformly on [X,2X] that |ψ(x+h) - ψ(x) - h| = o(h X^{-ε}) for h in [X^{1/2-ε}, X^{1/2}], then necessarily β ≤ 1/2 + o(1), and driving ε to a fixed positive constant forces RH.

Conclusion
This constitutes a concrete, rigorous reduction: a uniform power-saving in the short-interval prime counting error on the full dyadic interval [X,2X] at scales down to X^{1/2-ε} implies the Riemann Hypothesis. The proof isolates the contribution of a hypothetical off-line zero using the increment kernel and a phase-alignment argument, and shows that it cannot be canceled uniformly by the aggregate of the remaining zeros or the tail error.
