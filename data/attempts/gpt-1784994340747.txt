Attempt: An OR-compression barrier for SAT (showing a concrete approach to P ≠ NP is unlikely)

Goal
- Rigorously rule out a specific “batching/compression” route toward P ≠ NP: the existence of strong OR-compressions for SAT.
- Establish: If there is a polynomial-time compression that maps t SAT instances of length n into one instance of length m(n) with t superlogarithmic and m(n) ≪ t, preserving OR up to small error, then NP ⊆ coNP/poly. Hence such compressions are unlikely.
- Consequence: Any proof of P ≠ NP that proceeds by constructing such compressions and then diagonalizing on the compressed outputs faces a barrier.

Setup
- Fix ε ∈ (0, 1). Let t = t(n) be an integer parameter with t ≥ n^δ for some δ > 0 (in particular, t ≥ polylog n).
- An OR-compression for SAT with length bound m(n) is a randomized polynomial-time map Comp that, on input a t-tuple X = (φ1, …, φt) of 3-CNF formulas with total length ≤ n each, outputs a string y of length ≤ m(n), together with a deterministic polynomial-time predicate Dec such that:
  • Completeness: If at least one φi ∈ SAT, then with probability ≥ 2/3 over Comp’s coins, Dec(y) = 1.
  • Soundness: If all φi ∉ SAT, then with probability ≥ 2/3, Dec(y) = 0.
- Suppose m(n) ≤ t · n^o(1), and in particular m(n) = o(t). For concreteness and to isolate the core phenomenon, assume m(n) ≤ t/10.

Result (informal)
- If such an OR-compression exists for SAT with output length m(n) ≤ o(t) and constant (2/3, 1/3) completeness/soundness gap, then NP ⊆ coNP/poly.
- Therefore, unless NP ⊆ coNP/poly (which would collapse the polynomial hierarchy), such compressions do not exist.

Proof sketch
We give a self-contained variant of the Fortnow–Santhanam OR-compression barrier specialized to SAT and OR, streamlined to isolate the information bottleneck. The proof proceeds in three steps.

Step 1: Statistical separation from length bottleneck
- View Comp as mapping a multiset of instances to a short string. Consider two distributions over inputs X ∈ ({unsat, sat})^t:
  • D0: pick each φi uniformly among unsatisfiable 3-CNFs (conditioned unsatisfiable), independently.
  • D1(j): same as D0 except position j is replaced by a uniformly random satisfiable formula (conditioned satisfiable).
  For a fixed j, D1(j) differs from D0 by “planting” a single satisfiable instance at coordinate j.
- For each fixed j, completeness/soundness give a statistical test Dec ∘ Comp that distinguishes D1(j) from D0 with constant bias: the acceptance probability gap is ≥ 1/3 − o(1) (after standard constant-gap amplification if needed; we ignore amplification overhead since m(n) only shrinks further).
- Data processing inequality: Any function (Comp) cannot increase statistical distance. But observe the joint family {D1(j)}j=1..t are t different perturbations of D0, and Comp maps all of them into at most 2^{m(n)} outputs, with m(n) ≪ t. Intuitively, not all of these t perturbations can remain well-separated after compression; there must be collisions that smear out distinguishability, unless Dec uses advice that depends on which j was changed. Making this precise yields an averaging argument:

Claim 1 (Averaging/Index-loss lemma): If Comp maps t distributions {D1(j)} together with D0 into 2^{m} outputs with m < c·t for small constant c, then there exists a set J of indices of size Ω(t) such that the pairwise total variation distances TV(Comp(D1(j)), Comp(D0)) remain ≥ Ω(1) for all j ∈ J only if the images Comp(D1(j)) concentrate on disjoint sets of outputs. But 2^{m} disjoint large-probability sets can support at most O(2^{m}) such j’s. Consequently, for t ≫ 2^{m}, there exists j with TV(Comp(D1(j)), Comp(D0)) ≤ o(1), contradicting the correctness unless extra nonuniform information is provided.

- Concretely, since t ≥ 10·m, there must be “many” j for which post-compression distinguishing power deteriorates; otherwise, the constant bias tests for each j would require more than 2^{m} nearly-disjoint output caps, which is impossible.

Step 2: From index-loss to a nonuniform coNP refuter
- We turn the tension above into a coNP/poly algorithm for SAT.
- Advice: For each input size n and for the compression parameters (t, m), fix a small advice string A_n that identifies a “good” index j* and auxiliary randomness seeds such that Dec ∘ Comp distinguishes between D0 and D1(j*) with constant bias. The existence of such a j* for which distinguishability survives compression is guaranteed by correctness (for at least one coordinate, the one that is satisfiable).
- Given a single 3-CNF formula ψ of length n, we reduce its complement (UNSAT) to testing indistinguishability at coordinate j*:
  • Construct X by placing ψ at position j* and padding the other t − 1 positions with independently sampled unsatisfiable formulas (the sampler for unsatisfiable instances can be implemented by standard Cook–Levin encodings with built-in contradictions; we only require a sampler supported inside UNSAT).
  • Compute y = Comp(X) using public coins from advice (or by trying a small list of seeds), and output 1 (i.e., claim ψ ∉ SAT) if Dec(y) = 0 with high frequency over the padding choices; else output 0.
- Analysis: If ψ ∉ SAT then X ∼ D0, so the distinguisher Dec ∘ Comp rejects with high probability. If ψ ∈ SAT then X ∼ D1(j*), so Dec ∘ Comp accepts with noticeably larger probability. By standard Chernoff bounds over polynomially many paddings (bounded via pairwise-independent hash families encoded in the advice to keep everything within polynomial time), we amplify to a one-sided error coNP/poly refuter: an UNSAT certificate can be verified by checking that, for the fixed advice and randomness, the empirical acceptance frequency stays below the midpoint threshold.
- The subtlety from Step 1—that not all coordinates can be distinguished post-compression—does not harm the reduction because the advice precommits to a coordinate j* where distinguishability is certified to persist. This is exactly where nonuniformity enters; the advice announces a “good coordinate” plus randomness that witnesses the gap.

Conclusion of Step 2: We obtain a coNP/poly procedure that decides UNSAT (i.e., SAT ∈ NP ⊆ coNP/poly), hence NP ⊆ coNP/poly.

Step 3: Parameter check and robustness
- The only quantitative constraint needed is m(n) = o(t), say m ≤ t/10. The argument tolerates any constant completeness/soundness gap and standard Monte Carlo randomness for Comp.
- The proof applies to any NP-complete language under Karp reductions, not only 3SAT, and to any OR-preserving compression with short output length into an arbitrary target language decidable in polynomial time (Dec can be absorbed into the target language).
- This yields the promised barrier: unless NP ⊆ coNP/poly, no such OR-compression can exist.

Implications for approaches to P ≠ NP
- Any purported strategy that tries to “batch” many SAT instances into a single much shorter instance (or short string) while preserving the OR of satisfiability, as a prelude to diagonalization or speedup arguments, would imply NP ⊆ coNP/poly and is therefore highly unlikely.
- This concretely rules out a family of tempting ideas: compressing t ≫ m SAT queries into m-bit certificates that are then decided by a deterministic polynomial-time procedure while maintaining correctness gap.
- The barrier is robust to small constant error and to randomized compression, and it applies even if the target language of the compression is not SAT but any efficiently decidable language.

Notes on self-containment and rigor
- The core is an information-theoretic counting/averaging argument plus a padding-based reduction with nonuniform advice. The advice encodes seeds and a choice of a “good coordinate” that remains distinguishable post-compression.
- The statistical argument can be formalized via total variation distance, disjointization by Neyman–Pearson optimal tests, and a packing bound on many distinguishable distributions supported on 2^{m} outputs. The reduction uses standard amplification via small-bias spaces so the verifier remains polynomial-time and the advice length is polynomial.

Limitations
- This is a barrier result: it does not separate P from NP. It merely shows that one natural compression-based line cannot be pushed to resolve P ≠ NP (unless one accepts a major collapse).
- It leaves open compressions with output length m ≈ Θ(t) or above, and other non-OR aggregations.

VERDICT: PARTIAL
REASON: Ruled out strong SAT OR-compression approach unless NP⊆coNP/poly; a concrete barrier, not a separation.
