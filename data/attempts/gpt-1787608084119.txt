Attempt: A rigorous reduction that shifts codimension by taking products with projective spaces and, more generally, with “algebraic-cohomology” factors; in particular, it reduces the Hodge conjecture in arbitrary codimension on arbitrary X to the middle-codimension Hodge conjecture on products X × (P^1)^m.

Setup and notation:
- Work over C. Let X be smooth projective of dimension n.
- H^*(-) means singular cohomology with Q-coefficients; Hdg^{2r}(-) denotes Hodge classes in degree 2r.
- For a proper map f, f_* is the Gysin pushforward on cohomology; for a class α on a product, α ⋅ β is cup-product.
- A class is algebraic if it is in the image of the cycle class map CH^r(-)_Q → H^{2r}(-,Q).
- A smooth projective variety Y has algebraic cohomology if the Q-algebra H^*(Y,Q) is generated by algebraic classes of type (1,1). Examples: P^m, products (P^1)^m, more generally rational homogeneous varieties, cellular varieties.

Lemma 1 (Shift by P^1, equivalence in adjacent codimensions).
Let X be smooth projective and r ≥ 0. Then the following are equivalent:
(i) Every Hodge class in H^{2r}(X,Q) is algebraic.
(ii) Every Hodge class in H^{2r+2}(X × P^1,Q) is algebraic.
Proof.
- Künneth: H^{2r+2}(X × P^1) ≅ H^{2r+2}(X) ⊕ H^{2r}(X) ⊗ H^2(P^1).
- Let h ∈ H^2(P^1) be the hyperplane class, which is algebraic.
- Any α ∈ Hdg^{2r+2}(X × P^1) decomposes uniquely as α = π_X^*γ ⊕ (π_X^*β) ∪ (π_{P^1}^*h), with γ ∈ Hdg^{2r+2}(X), β ∈ Hdg^{2r}(X).
- If (i) holds, choose algebraic cycles Γ of codimension r+1 on X for γ and Z of codimension r on X for β. Then α is the class of the algebraic cycle (Γ × P^1) + (Z × pt) on X × P^1, so (ii) holds.
- Conversely, suppose (ii) holds. Pick α = (π_X^*β) ∪ (π_{P^1}^*h) with β ∈ Hdg^{2r}(X). By (ii), α is algebraic: α = cl(W) for some W ∈ CH^{r+1}(X × P^1)_Q. Let η ∈ CH^0(P^1)_Q be the class of a point, representing a cohomology class dual to h under ∫_{P^1}. Then
  β = π_{X*}(α ∪ π_{P^1}^*[pt]) in H^{2r}(X),
and on the cycle level β is represented by π_{X*}(W ⋅ (X × [pt])), hence is algebraic. Therefore (i) holds. QED.

Lemma 2 (General shift via algebraic-cohomology factor, with projection formula).
Let Y be smooth projective with algebraic cohomology. Fix t ≥ 0. For any smooth projective X and any r ≥ 0, the following are equivalent:
(i) Every Hodge class in H^{2r}(X) is algebraic.
(ii) Every Hodge class in H^{2r+2t}(X × Y) lying in the Künneth summand H^{2r}(X) ⊗ H^{2t}(Y) is algebraic.
Moreover, if (i) holds for all r on X, then every Hodge class in H^{2*}(X × Y) is algebraic.
Proof.
- Because H^*(Y) is generated by algebraic (1,1)-classes, every class in H^{2t}(Y) is algebraic and Hodge. Fix a Q-basis {u_j} of H^{2t}(Y) and a Q-basis {v_j} of H^{2dim Y-2t}(Y) with ∫_Y u_j ∪ v_k = δ_{jk}. Choose algebraic cycles U_j, V_j representing u_j, v_j.
- Any α in the Künneth summand H^{2r}(X) ⊗ H^{2t}(Y) can be written α = Σ_j π_X^*β_j ∪ π_Y^*u_j with β_j ∈ H^{2r}(X). If (i) holds, pick cycles Z_j on X for β_j; then α is represented by Σ_j Z_j × U_j, hence algebraic.
- Conversely, suppose α as above is algebraic: α = cl(W) for W ∈ CH^{r+t}(X × Y)_Q. Then
  β_j = π_{X*}(α ∪ π_Y^*v_j) = cl(π_{X*}(W ⋅ (X × V_j))),
so each β_j is algebraic. Therefore (i) holds. The “moreover” follows since every Künneth summand involves only Hodge classes from X tensored with algebraic classes from Y, and the same projection/pushforward reduces algebraicity to X. QED.

Corollary 3 (Reduction to middle codimension on products with (P^1)^m).
Fix X smooth projective of dimension n and r ∈ {0,…,n}. Choose m ≥ max(0,n−r) and set Y = (P^1)^m. Then:
- Hodge(X, codim r) holds if and only if Hodge(X × Y, codim r+t) holds for t = n + m − r (which satisfies 0 ≤ t ≤ m).
- In particular, Hodge(X, all codimensions) is equivalent to Hodge in middle codimension on X × (P^1)^m for sufficiently large m.
Proof.
Apply Lemma 2 with Y = (P^1)^m whose cohomology is generated by degree-2 hyperplane classes, and choose t so that r + t = dim(X × Y)/2 = n + m. Then codimension r on X shifts to middle codimension on X × Y. The equivalence is exactly Lemma 2. QED.

Remarks and consequences:
- This yields a clean and fully algebraic reduction: the Hodge conjecture in arbitrary codimension on arbitrary X is equivalent to the middle-codimension Hodge conjecture on X × (P^1)^m, where all extra cohomology from Y is controlled by algebraic classes and can be projected out via algebraic correspondences (pushforward after intersecting with pullbacks of cycles on Y).
- The proof uses only basic tools: Künneth, algebraicity of cohomology on Y, and functoriality of cycle class maps with respect to pullback, pushforward, and intersection.
- While variants of “stabilization by projective space” are folklore, the above gives a precise, self-contained equivalence including an explicit extraction formula for the reduced class:
  β_j = π_{X*}(W ⋅ (X × V_j)).
- This formulation isolates the primitive cohomology obstacle to the middle-degree case, but also shows that products with (P^1)^m introduce no new difficulty beyond X itself.

Limitations:
- This does not solve middle-degree cases; it only packages a reduction. The extraction relies on having an algebraic-cohomology factor Y; for general Y the converse direction would require algebraic Künneth projectors (a case of the Standard Conjectures).
- The reduction is “tautological” from the viewpoint of Künneth, but the cycle-level projection given here is explicit and unconditional for Y with algebraic cohomology.
