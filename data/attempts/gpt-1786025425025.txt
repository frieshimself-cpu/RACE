Attempt: A support-controlled decomposition of the diagonal implies the Hodge conjecture in a fixed codimension

Setup. Let X be a smooth projective complex variety of dimension n, and fix 1 ≤ p ≤ n. Work with rational cohomology and cycle classes. For a correspondence Γ ⊂ A×B of codimension r, its cohomological action Γ_*: H^i(A,Q) → H^{i+2(r−dim A)}(B,Q) is defined by
Γ_*(α) := pr_{2*}(pr_1^*α ∪ [Γ]).

Key hypothesis (support-controlled decomposition). Assume there exist closed subvarieties V,W ⊂ X with
- dim V ≤ p,
- codim W ≥ p,
and algebraic cycles Z_V, Z_W ∈ CH^n(X×X)_Q such that in cohomology
[Δ_X] = [Z_V] + [Z_W],
with Supp Z_V ⊂ V×X and Supp Z_W ⊂ X×W.

Claim (main). Under the hypothesis, every Hodge class in H^{2p}(X,Q) is the class of a Q-linear combination of codimension-p algebraic cycles. Equivalently, the Hodge conjecture holds for X in degree 2p.

Proof sketch.

1) Identity decomposition via correspondences.
For any α ∈ H^{2p}(X,Q), using the identity action of the diagonal on cohomology,
α = pr_{2*}(pr_1^*α ∪ [Δ_X]) = (Z_V)_*(α) + (Z_W)_*(α).

2) Factorization through the supports.
Because Supp Z_V ⊂ V×X, there is Θ ∈ CH^v(V×X)_Q (v := dim V) with Z_V = (i×id_X)_*Θ, where i: V ↪ X. Similarly, because Supp Z_W ⊂ X×W, there is Ψ ∈ CH^w(X×W)_Q (w := dim W) with Z_W = (id_X×j)_*Ψ, where j: W ↪ X.
On cohomology, these yield factorisations
(Z_V)_* = Θ_* ∘ i^*, and (Z_W)_* = j_* ∘ Ψ_*,
with degree shifts:
- Θ_*: H^k(V) → H^k(X) (since codim Θ = v = dim V),
- Ψ_*: H^k(X) → H^{k+2(w−n)}(W) (since codim Ψ = w).

3) Analysis of the V-term.
We have (Z_V)_*(α) = Θ_*(i^*α) with i^*: H^{2p}(X) → H^{2p}(V).
- If 2p > 2v (i.e., p > v), then H^{2p}(V) = 0 by dimension, so (Z_V)_*(α) = 0.
- If 2p = 2v (i.e., p = v), then i^*α ∈ H^{2v}(V) is a top-degree Hodge class; H^{2v}(V,Q) is one-dimensional, generated by the fundamental class [V] (algebraic). Since correspondences respect cycle classes, Θ_* sends [V] to the cycle class of the algebraic cycle pr_{2*}(Θ ∩ pr_1^*[V]) on X, hence (Z_V)_*(α) is algebraic. In either case, the V-term is algebraic.

4) Analysis of the W-term.
We have (Z_W)_*(α) = j_* (Ψ_*(α)) with Ψ_* lowering degree by 2(n−w) = 2 codim(W). Compute the target degree:
deg Ψ_*(α) = 2p + 2(w−n) = 2(p − codim(W)) ≤ 0.
- If codim(W) > p, then the degree is negative and Ψ_*(α) = 0, so (Z_W)_*(α) = 0.
- If codim(W) = p, then Ψ_*(α) ∈ H^0(W,Q). Any H^0-class is of Hodge type (0,0), i.e., a Q-linear combination of classes of connected components of W. Pushing forward by the Gysin map j_*: H^0(W) → H^{2p}(X) yields a Q-linear combination of the codimension-p cycle classes of the components of W. Hence (Z_W)_*(α) is algebraic.

5) Conclusion.
α equals the sum of two algebraic classes, so α is algebraic. Therefore all Hodge classes in H^{2p}(X,Q) are algebraic, as claimed.

Remarks and scope.
- The hypothesis is a concrete, checkable cohomological decomposition condition. It is reminiscent of Bloch–Srinivas type decompositions but is tailored to force algebraicity of Hodge classes in a fixed codimension p by bounding the supports on the two factors.
- In particular, if one can construct such a decomposition for X and p (e.g., via coniveau ≥ p on the second factor and dimension ≤ p on the first), then the Hodge conjecture follows in codimension p for X.
- This gives a reduction: establishing such decompositions (for instance, by geometric arguments, spread-out techniques, or motivic projectors with controlled support) suffices for HC in that degree.

Limitations.
- The main result is conditional: it provides a sufficient geometric criterion rather than an unconditional proof. Producing the required decomposition is nontrivial and, in general, as hard as instances of the conjecture. Nonetheless, it isolates a precise target that may be more accessible in families or special classes (e.g., when coniveau or niveau conditions can be verified).
