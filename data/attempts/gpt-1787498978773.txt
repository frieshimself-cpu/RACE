Attempt: A parametrized barrier against “moderately-natural” lower bounds

Set-up and notation
- For n∈N, let F_n be the set of Boolean functions on {0,1}^n. Write m = 2^n for the truth-table length. The uniform distribution over F_n is denoted U_n.
- A property A_n ⊆ F_n is given a truth table of length m and outputs accept/reject.
- Density of A_n is dens(A_n) := |A_n| / |F_n| = |A_n| / 2^m.
- A_n is useful against SIZE(n^k) if for all sufficiently large n and all circuits C of size ≤ n^k computing some f∈F_n, we have f ∉ A_n.
- A PRF family against time T with distinguishing threshold ε for input length n is a distribution PRF_n over SIZE(n^k) functions such that for any algorithm D with runtime ≤ T(n), |Pr_{f←PRF_n}[D(f)=1] − Pr_{g←U_n}[D(g)=1]| < ε(n).

Lemma (Parametrized natural-proofs barrier)
Fix α∈(0,1) and k∈N. Suppose there exists a pseudorandom function family PRF_n ⊆ SIZE(n^k) that is secure against time 2^{n^α} distinguishers with advantage at least 2^{-n^α}; that is, for all algorithms D running in time ≤ 2^{n^α},
|Pr_{f←PRF_n}[D(f)=1] − Pr_{g←U_n}[D(g)=1]| < 2^{-n^α}.
Then there is no sequence of properties A_n ⊆ F_n such that simultaneously:
1) decidability: given the truth table of f∈F_n (length m=2^n), A_n(f) can be computed in time at most 2^{m^α} = 2^{2^{α n}};
2) largeness: dens(A_n) ≥ 2^{-m^α} = 2^{-2^{α n}};
3) usefulness: A_n excludes SIZE(n^k), i.e., for all f computable by circuits of size ≤ n^k, A_n(f)=0, for all sufficiently large n.

Proof sketch
Assume, towards contradiction, that such A_n exist. Consider the distinguisher D that, on input the truth table of a function h∈F_n, computes A_n(h) and outputs that bit. Its runtime on inputs of length m is by (1) at most 2^{m^α}. Interpreting h as a function on n-bit inputs, the underlying security parameter is n, and D runs within the allowed 2^{n^α} time bound because 2^{m^α} = 2^{2^{α n}} ≤ 2^{n^α} is false as written. We need to align parameters carefully:

- The security parameter for the PRF is the input length n of functions in F_n.
- D operates on truth tables of length m = 2^n, not on succinct circuits. Thus the time bound for D as a function of n is T_D(n) = time(A_n on m=2^n) ≤ 2^{(2^n)^α}.

Hence, to use D to contradict PRF security, we must assume PRF security against time 2^{(2^n)^α} distinguishers at input length n. We therefore restate the security assumption in terms of m:

Assumption’. There exists a PRF family PRF_n ⊆ SIZE(n^k) such that for all distinguishers D running in time ≤ 2^{(2^n)^α} on truth-table input, we have
|Pr_{f←PRF_n}[D(f)=1] − Pr_{g←U_n}[D(g)=1]| < 2^{-(2^n)^α}.

This is exactly the same α-parameterization, but measured against algorithms whose time is bounded as a function of truth-table length m. Equivalently: for functions on m-bit domains, security holds against 2^{m^α}-time distinguishers with advantage < 2^{-m^α}.

Under Assumption’, D is an admissible distinguisher. Its distinguishing advantage is at least
Pr_{g←U_n}[A_n(g)=1] − Pr_{f←PRF_n}[A_n(f)=1].
By largeness (2), Pr_{g←U_n}[A_n(g)=1] ≥ 2^{-m^α}. By usefulness (3) and the fact PRF_n ⊆ SIZE(n^k), we have A_n(f)=0 for all f in the PRF support, so Pr_{f←PRF_n}[A_n(f)=1]=0. Thus D’s advantage is at least 2^{-m^α}, contradicting Assumption’.

Therefore, no property satisfying (1)–(3) can exist under Assumption’.

Remarks and consequences
- The lemma shows a quantitative barrier: any approach to lower bounds via “moderately-natural” properties—that is, properties testable in sub-exponential truth-table time 2^{m^α} and holding for at least a 2^{-m^α} fraction of functions—cannot rule out SIZE(n^k) under the corresponding PRF assumption.
- Many concrete, constructive lower-bound methods yield properties decidable in time poly(m) from the truth table, which is much smaller than 2^{m^α} for any fixed α∈(0,1) and large m. Thus, assuming PRFs secure against poly(m)-time distinguishers with even tiny advantage 1/poly(m), the same reasoning rules them out. The presented α-parameter tracks how far beyond polynomial-time constructivity one would have to go to evade the barrier, given a corresponding PRF security level.
- The statement is independent of P vs NP itself; it is an analysis of a family of proof strategies. It cleanly isolates the quantitative tradeoff between largeness, constructivity, and assumed PRF security.

Tightness and limits
- The barrier vanishes if any of the three parameters degrades enough: e.g., if the density of the property is super-exponentially small in m (so that random functions almost never satisfy it), or if the property is not efficiently checkable from the truth table (e.g., requires time 2^{Ω(m)}), or if sufficiently strong PRFs do not exist. This clarifies which axis an eventual successful lower-bound property must push on.
- The proof is black-box and unconditional given Assumption’. No step relies on history or external theorems beyond the stated security premise and definitions.

Conclusion
This is a rigorous, self-contained obstruction showing that a broad band of “moderately-natural” property-based approaches cannot yield superpolynomial lower bounds against SIZE(n^k) under a quantified PRF assumption. It does not resolve P vs NP, but it narrows a region of techniques and quantifies what strength of constructivity and largeness must be avoided to have a chance of success.
