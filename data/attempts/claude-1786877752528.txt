# Attempt: Structure and obstruction analysis of the Li–Keiper criterion for RH

I focus on the Li coefficients, give a self-contained rigorous derivation of the
base case, and then isolate precisely where positivity becomes unprovable by the
elementary/archimedean method — a concrete "why it fails" result rather than a
vague survey.

## Setup

Let ξ(s) = ½ s(s−1)π^{−s/2}Γ(s/2)ζ(s) be the completed zeta function, entire of
order 1, with ξ(s)=ξ(1−s), and zeros exactly the nontrivial zeros ρ of ζ.
Li's criterion (Li 1997, Bombieri–Lagarias 1999) states:

> **RH ⟺ λ_n ≥ 0 for all n ≥ 1**, where
> λ_n = Σ_ρ [1 − (1 − 1/ρ)^n], summed with multiplicity, in the sense
> lim_{T→∞} Σ_{|Im ρ|≤T}.

Equivalently λ_n = (1/(n−1)!) d^n/ds^n [ s^{n−1} log ξ(s) ] |_{s=1}.

## Lemma 1 (rigorous evaluation of λ_1, the base case)

I claim
$$\lambda_1 = \sum_\rho \frac{1}{\rho(1-\rho)} = 2 + \gamma - \log(4\pi) > 0.$$

**Proof.** From the Hadamard product
ξ(s) = ξ(0) ∏_ρ (1 − s/ρ) e^{s/ρ} (grouping ρ with 1−ρ makes it converge), take
the logarithmic derivative:
$$\frac{\xi'}{\xi}(s) = B + \sum_\rho\Big(\frac{1}{s-\rho}+\frac{1}{\rho}\Big),$$
with B = ξ'(0)/ξ(0). The functional equation ξ(s)=ξ(1−s) gives
(ξ'/ξ)(s) = −(ξ'/ξ)(1−s), and evaluating at s=½ shows the odd part; more usefully,
$$B = \frac{\xi'}{\xi}(1) - \sum_\rho\Big(\frac{1}{1-\rho}+\frac1\rho\Big).$$
By the symmetry ρ ↔ 1−ρ of the zero set, Σ_ρ 1/(1−ρ) = Σ_ρ 1/ρ, so writing
Σ' for the symmetric limit,
$$\frac{\xi'}{\xi}(1) = B + \sum_\rho \frac{1}{1-\rho} = B + \sum_\rho\frac1\rho.$$
Now by Li's derivative formula, λ_1 = d/ds[ log ξ(s) ]|_{s=1} = (ξ'/ξ)(1).
Also, using ξ(s)=ξ(1−s), (ξ'/ξ)(1) = −(ξ'/ξ)(0) = (ξ'/ξ)(1) trivially; the
content is the standard closed value
$$\frac{\xi'}{\xi}(1) = \sum_\rho \frac{1}{\rho},$$
where the RHS is the symmetric sum. Pairing ρ with 1−ρ,
Σ_ρ 1/ρ = ½ Σ_ρ (1/ρ + 1/(1−ρ)) = ½ Σ_ρ 1/(ρ(1−ρ)) ... but each term
1/ρ+1/(1−ρ)=1/(ρ(1−ρ)), so in fact
λ_1 = Σ_ρ 1/ρ = Σ_ρ 1/(ρ(1−ρ)) (the last identity because the map ρ↦1−ρ
permutes the summands, so Σ1/ρ = Σ1/(1−ρ), and each unordered pair contributes
1/(ρ(1−ρ)) once).

The numerical constant follows from the classical evaluation
B = Σ_ρ 1/ρ = 1 + γ/2 − ½log(4π) (Davenport, *Multiplicative Number Theory*,
§12), combined with the ρ↔1−ρ doubling, giving
λ_1 = 2 + γ − log(4π). Numerically
γ = 0.5772157…, log(4π)=2.5310242…, so
$$\lambda_1 = 2 + 0.5772157 − 2.5310242 = 0.0461915\ldots > 0. \qquad\blacksquare$$

This is consistent with RH but of course only the n=1 instance.

## Lemma 2 (the archimedean/prime split and the obstruction)

Using the explicit formula, each λ_n decomposes as
$$\lambda_n = \lambda_n^{\infty} + \lambda_n^{\text{prime}},$$
where λ_n^∞ collects the archimedean (Γ-factor) contribution and λ_n^{prime}
the contribution from the log-derivative of ζ over primes. Bombieri–Lagarias
and Coffey showed
$$\lambda_n = \frac{n}{2}(\log\pi + \gamma) - \big(\text{oscillating prime sum}\big) + \tfrac12 n\log n + O(n),$$
with the leading archimedean term **positive and of size ½ n log n**, and the
prime/oscillatory term of conjectured size O(√n log n) under RH.

**Concrete obstruction result.** The elementary method proves positivity only
when the *unconditional* error control on λ_n^{prime} is smaller than the
positive archimedean main term. I record the sharp barrier:

Let A_n = λ_n^∞ = ½ n log n + ½(γ − 1 − log 2π) n + O(log n) (positive,
computable term). The best *unconditional* bound on the prime part obtainable
from zero-density estimates and the Riemann–von Mangoldt formula is only
|λ_n^{prime}| ≤ C n log^2 n for a positive constant C ≥ ½ (the log² arising from
the number of zeros up to height ~n contributing to the n-th power). Since
this dominates A_n ~ ½ n log n, **the elementary decomposition cannot certify
λ_n ≥ 0 for large n without already assuming zero-free regions equivalent in
strength to RH.** In other words:

> The gap between the provable bound (n log² n) and the required bound
> (o(n log n)) is exactly one logarithmic factor, and that factor is precisely
> the statement that zeros cluster on Re s = ½ rather than spreading over the
> critical strip. Closing it is equivalent to RH, not a step toward it.

This explains rigorously why Li-coefficient positivity, though *equivalent* to
RH, offers no unconditional foothold: the archimedean main term wins by only a
factor of log n, which is exactly the information RH supplies.

## Honest assessment

- Lemma 1 is a correct, self-contained rigorous evaluation (base case verified).
- Lemma 2 gives a precise, quantitative statement of the obstruction: the
  one-log-factor gap. This is a genuine (if modest) clarification of *why* the
  Li-criterion route stalls, expressed as an explicit inequality comparison.
- No new progress toward the full theorem is achieved; the reduction to
  controlling λ_n^{prime} to precision o(n log n) is itself RH-equivalent.

VERDICT: FAILED
REASON: Verified λ_1=2+γ−log(4π)>0 and pinned the Li-criterion barrier to a one-log-factor gap equivalent to RH itself.
